1. Установка (install.bat)

Этот батник нужен для первичной настройки.

    Что делает: Подключается по ADB, создает нужные папки (/data/myos/www), закидывает свежие файлы и проверяет, установлен ли Python (если нет — ставит).

    Как использовать: Запускаешь install.bat, вводишь IP колонки, ждешь надпись INSTALLATION COMPLETE!.

2. Запуск (start.bat)

Этот батник нужен для ежедневного использования.

    Когда запускать: Каждый раз, когда ты хочешь включить свою ОС.

    Что делает: Подключается по ADB, запускает сервер и открывает браузер с твоей ОС.

    Как использовать: Запускаешь start.bat, вводишь IP. Откроется черное окно с сервером (не закрывай его, пока пользуешься ОС) и браузер. 
    
    Когда захочешь выключить ОС — просто закрой это черное окно сервера.

3. Полное удаление (uninstall.bat)

Этот батник нужен, чтобы полностью стереть следы ОС с колонки.

    Когда запускать: Если ты хочешь освободить место, сбросить всё до заводского состояния или начать установку с чистого листа.

    Что делает: Убивает сервер, удаляет папку /data/myos со всеми файлами и удаляет скрипты автозапуска (если они остались).

    Как использовать: Запускаешь uninstall.bat, вводишь IP. Ждешь UNINSTALL COMPLETE!. После этого ОС на колонке больше нет.
