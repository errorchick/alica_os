1. Установка (install.bat)

Этот батник нужен для первичной настройки.

    Что делает: Подключается по ADB, создает нужные папки (/data/myos/www), закидывает свежие файлы и проверяет, установлен ли Python (если нет — ставит).

    Как использовать: Запускаешь install.bat, вводишь IP колонки, ждешь надпись INSTALLATION COMPLETE!.

2. Запуск (start.bat)

Этот батник нужен для ежедневного использования.

    Когда запускать: Каждый раз, когда ты хочешь включить свою ОС.

    Что делает: Подключается по ADB, запускает сервер и открывает браузер с твоей ОС.

    Как использовать: Запускаешь start.bat, вводишь IP. Откроется черное окно с сервером (не закрывай его, пока пользуешься ОС) и браузер. 
    
    Когда захочешь выключить ОС — просто закрой это черное окно сервера.

3. Полное удаление (uninstall.bat)

Этот батник нужен, чтобы полностью стереть следы ОС с колонки.

    Когда запускать: Если ты хочешь освободить место, сбросить всё до заводского состояния или начать установку с чистого листа.

    Что делает: Убивает сервер, удаляет папку /data/myos со всеми файлами и удаляет скрипты автозапуска (если они остались).

    Как использовать: Запускаешь uninstall.bat, вводишь IP. Ждешь UNINSTALL COMPLETE!. После этого ОС на колонке больше нет.

    Вот эта галочка «Не позволять 192.168.1.133:8080 снова вас запрашивать» — это стандартная защита браузера (особенно в Firefox). Если ты на неё случайно нажал или если браузер решил, что сайт спамит запросами (а он спамит, потому что мы каждую секунду опрашиваем сервер для обновления файлов), браузер блокирует все дальнейшие alert, confirm и prompt с этой страницы.

После этого:

    Когда ты нажимаешь «Удалить», выскакивает confirm(...).

    Браузер его молча блокирует (потому что ты запретил).

    JavaScript думает, что ты нажал «Отмена» (возвращает false).

    Удаление не происходит, создание не происходит. Интерфейс просто перестает реагировать на действия, требующие подтверждения.

Именно поэтому «сначала работает, потом перестаёт».
🛠 Как это исправить:

    В браузере нажми на иконку замка (или настройки сайта) рядом с адресной строкой 192.168.1.133:8080.

    Найди в списке разрешений пункт «Показывать диалоговые окна» (или «Диалоги», «JavaScript-диалоги»).

    Поставь «Разрешить» (или удали сайт из списка исключений).

    Нажми Ctrl+F5 для перезагрузки страницы.

Если это не помогло, просто открой сайт в режиме инкогнито или в другом браузере (Chrome/Edge). Там эта галочка не нажимается случайно.
